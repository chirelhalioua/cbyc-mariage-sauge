# C by C — Modèle mariage sauge

Modèle indépendant d'invitation de mariage réalisé avec Nuxt 3.

## Installation

```bash
npm install
npm run dev
```

## Déploiement

Le projet peut être importé dans Vercel comme projet Nuxt. La page d'accueil est `pages/index.vue`.

Le formulaire RSVP est actuellement une démonstration côté navigateur : les réponses ne sont pas enregistrées ni envoyées.
